# Data-immersion-and-wrangling-

Objective
This project is about understanding and cleaning data using Python. The main goal is to convert raw data into a clean and organized format for better analysis

Tools & Technologies Used
Python
Pandas
NumPy
Jupyter Notebook
CSV File Format

How It Worked
The project started by loading the dataset into Python using Pandas.
The data was explored to understand its structure, missing values, and duplicate records.
After identifying issues, data cleaning techniques were applied such as handling missing values, removing duplicates, and formatting the data properly.
Finally, the cleaned dataset was saved as a new CSV file.

Workflow
1. Import libraries
2. Load dataset
3. Explore dataset
4. Check missing values
5. Remove duplicate records
6. Clean and transform data
7. Save cleaned dataset

Files Included

Conclusion
This project helped in understanding the process of data immersion and data wrangling. The dataset was successfully cleaned and transformed into a structured format ready for analysis and visualization.
